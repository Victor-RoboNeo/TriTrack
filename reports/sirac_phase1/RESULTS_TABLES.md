## 1. 当前实验是什么意思

研究问题：

> 人只给头和两只手的稀疏 SE(3) 意图时，下半身是否应该继续由 Stage-2 直接输出 29 维关节，还是改成一个 **机器人自己拥有的 7 维 realization 指令**，再交给冻结的 HTD 下肢控制器去实现。

人拥有的意图始终只有：

- 头姿态 SE(3)
- 左手姿态 SE(3)
- 右手姿态 SE(3)

7 维指令 **不是** 人手柄，也不是新的人机接口。它是从 Stage-2 名义运动里抽出来的机器人内部变量：

```
c = [vx, vy, 偏航角速度, 躯干高度, roll, pitch, 相对 yaw]
```

本阶段 **不训练** ADAPT 残差、扩散、PPO 恢复、地形分类器。只测「把冻结 HTD 学生接到这条 7 维瓶颈上」是否立刻有用。

三条对照：

| 名称 | 含义 |
| --- | --- |
| **Baseline A** | 已验证的 parent：Mapper-B（72D）→ Stage-2 `g_φ,50000` → 全身 29 关节。这是旧方法。 |
| **Baseline B** | 同一套稀疏意图和 Stage-2 名义运动；上肢仍用 Stage-2；腿和腰改成「抽出 7D → 冻结 HTD LBC」。 |
| **Baseline C** | 与 B 相同，但手臂固定在 HTD 零位。用来判断失败是上肢扰动，还是 7D 移植本身坏了。 |

判定规则（事先写好的）：

| 情况 | 若出现 | 含义 |
| --- | --- | --- |
| Case A | B/C 更稳，且头手变差很小 | 7D 瓶颈成立，可以做 ADAPT |
| Case B | C 还行、B 在动臂时垮 | 瓶颈可用，但需要未来意图/上肢扰动训练 |
| Case C | 静臂也对、映射也对，头手仍大幅变差 | 先查坐标系/指令/PD，不要加网络 |
| Case D | 冻结失败、微调能救 | 保留 7D 接口，重训统一 LBC |

当前 Isaac 结果 **暂定 Case C**（移植本身未通，不是 ADAPT 的时候）。

## 3. 测评指标是什么

对每个 env / 每条 clip，在 400 步上取平均，再对 10 条 clip 取平均。

| 指标 | 定义 | 怎么读 |
| --- | --- | --- |
| 头 / 左腕 / 右腕 **位置误差** (m) | 机器人对应 link 与 clip 参考位置的欧氏距离 | 越小越好；厘米级才像 parent |
| 头 / 左腕 / 右腕 **旋转误差** (rad) | 四元数测地线角 | 越小越好 |
| **SR@5cm** | 三部位平均位置误差 &lt; 5 cm 的时间比例 | 越高越好 |
| **D_intent** | 三部位平均位置误差 + 0.2 × 平均旋转误差 | 稀疏意图总偏差 |
| **D_intent_excess** | `D_intent(新) − D_intent(A)` | 新方法相对 parent 多牺牲了多少意图 |
| **command_track_err** | 发给 LBC 的 7D 指令 vs 机器人实测 7D（仅 B/C） | 下肢是否跟上自己的 realization |
| **action_smoothness** | 相邻动作差分的范数 | 越小越平滑 |
| **policy_latency_ms** | 每步墙钟（含仿真） | 仅作耗时参考 |
| `fell` / `success` | 本轮用腕部高度 0.25 m 的 `ee_z` 触发 | **A 也全是 1，不能当摔倒率** |

未填（NaN）：足滑、接触冲击、执行器饱和、质心稳定。不要把它们写成 0。

## 5. 当前结论（对应表格，而不是成功率）

1. **Parent（A）可用**：头手大约 7–9 cm，SR@5cm 约 0.61。评测链路没有把旧方法测坏。
2. **7D 冻结移植（B）目前不可用**：头手大约 2 m，`D_intent_excess ≈ 2.16`。
3. **不是上肢扰动（C）**：静臂同样约 2 m。
4. **不要看 `fell=1.0`**：A/B/C 都被腕部 `ee_z` 打成失败；比较跟踪误差。
5. **下一步不是 ADAPT**：按 Case C，先查指令坐标系、躯干归属、AnyBody PD / action scale 与 HTD `q=q_htd+0.25a` 是否一致。修好 B/C 的跟踪量级接近 A 之前，不要加残差网络。
